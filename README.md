## Opis projektu

Celem projektu jest praktyczna nauka podstaw systemu kontroli wersji Git oraz
współpracy na platformie GitHub. Aplikacja jest prosta, dzięki czemu można
skupić się na takich zagadnieniach jak:

- tworzenie commitów,
- praca z gałęziami (branch),
- tworzenie pull requestów,
- rozwiązywanie konfliktów,
- współpraca z innymi osobami w repozytorium.

## Instalacja

1. Sklonuj repozytorium:

   ```bash
   git clone https://github.com/<twoj-login>/<nazwa-repozytorium>.git
   ```

2. Przejdź do katalogu projektu:

   ```bash
   cd <nazwa-repozytorium>
   ```

3. (Opcjonalnie) Utwórz i aktywuj wirtualne środowisko:

   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux / macOS
   venv\Scripts\activate         # Windows
   ```

## Uruchomienie

```bash
python main.py
```
