## Opis projektu

Celem projektu jest praktyczna nauka podstaw systemu kontroli wersji Git oraz
współpracy na platformie GitHub. Aplikacja jest prosta, dzięki czemu można
skupić się na takich zagadnieniach jak:

- tworzenie commitów,
- praca z gałęziami (branch),
- tworzenie pull requestów,
- rozwiązywanie konfliktów,
- współpraca z innymi osobami w repozytorium.
